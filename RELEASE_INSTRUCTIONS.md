# Release Build Instructions

This document outlines the steps to build the extension and the exact files required for the release zip folders.

## Build Commands

Before creating the zip files, ensure you have built the latest version of the code. Run the following commands in your terminal:

1. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
2. Bundle the vendor files:
   ```bash
   npm run bundle:emailjs
   ```
   
   Note: only run this when you update dependencies or if
   `src/vendors/emailjs-mime-parser.bundle.js` is missing or out-of-date. The
   repository often already contains the bundled file and `npm run build` will
   include its code in `dist/`, so if tests and the build are working you do
   not need to run it every time.
3. Build the extension files for production:
   ```bash
   npm run build
   ```
4. Create the release folders automatically:
   ```bash
   npm run release
   ```
   This will create two folders (`find-my-accounts-<version>` and `find-my-accounts-<version>-source`) one level above the project root.

## Zip Folder Contents

For a release, you need to create two zip files from the folders generated by `npm run release`. Here are the files and folders that are included in each.

### 1. `find-my-accounts-<version>` (The Extension)
This zip contains only the files required for the extension to run in the browser. Upload this to the Chrome Web Store / Firefox Add-ons.

*   `manifest.json`
*   `dist/` (Generated by the build command)
*   `src/popup/popup.html`
*   `src/popup/popup.css`
*   `src/assets/`
*   `_locales/`
*   `LICENCE`
*   `LICENSES/`

*(Note: You do not need the rest of the `src/` folder because the JavaScript is bundled into the `dist/` folder).*

### 2. `find-my-accounts-<version>-source` (The Source Code)
This zip contains the raw source code. This is required by platforms like Mozilla Add-ons when your extension uses bundled/minified code.

*   `package.json`
*   `package-lock.json`
*   `vitest.config.js`
*   `manifest.json`
*   `README.md`
*   `LICENCE`
*   `LICENSES/`
*   `src/` (The entire folder)
*   `_locales/`
*   `test/`

*(Note: Do **not** include the `node_modules/` or `dist/` folders in the source zip, as they are generated from the source).*
