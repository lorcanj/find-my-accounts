FAQ

Does this access my email account?
No. It never connects to any email account, Gmail or otherwise. You export an .mbox file yourself (via Google Takeout, Thunderbird, Apple Mail, etc.) and upload that file directly.
Is any of my data uploaded anywhere?
No. Parsing happens entirely in your browser via a Web Worker. Nothing leaves your machine: no server, no analytics, no tracking.
What permissions does the extension need?
None. The manifest requests zero browser permissions; everything runs off an explicit file pick.
Can it find every account I've ever created?
No tool can guarantee that. It finds accounts it can detect from patterns in your email archive (welcome emails, receipts, password resets, and more). It won't catch accounts that never emailed you or where those emails were deleted.
Does it read the body of my emails?
No. Detection only looks at email headers, such as the sender address, display name, and subject line. Email bodies aren't analysed.
What about accounts that never emailed me?
Those won't show up. Detection is entirely email-based, so if a service never sent you a confirmation, receipt, or notification, there's no trace to find.
Which email providers does it work with?
Any provider you can export as a standard .mbox file from, including Gmail (via Google Takeout), Thunderbird, Apple Mail, and Proton Mail.
What if my provider isn't listed?
Direct .mbox export is only built into a few providers, such as Gmail (via Google Takeout) and Proton Mail. For others, such as Outlook.com or Yahoo, connect the account via IMAP to a desktop client like Thunderbird and export the folder from there as .mbox.
How long does scanning take?
It depends on archive size. The streaming parser handles multi-GB files without freezing the browser, but very large archives will take longer than a quick scan.
What do I do once it finds an account?
Each result links to a deletion page (via the JustDeleteMe dataset) with a difficulty rating, so you can go straight to cancelling or deleting it.
